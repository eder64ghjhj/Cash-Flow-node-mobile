# 💸 Cash Flow — Controle Financeiro Mobile-First

Aplicação web de controle de fluxo de caixa com arquitetura cliente-servidor, desenvolvida com Node.js no back-end e interface responsiva otimizada para dispositivos móveis.

## 🚀 Funcionalidades

- Registro de entradas e saídas financeiras
- Visualização do saldo atual em tempo real
- Interface responsiva e mobile-first
- Persistência de dados com MySQL

## 🛠️ Tecnologias Utilizadas

| Camada | Tecnologia |
|--------|-----------|
| Back-end | Node.js + Express |
| Banco de Dados | MySQL |
| Front-end | HTML5, CSS3, JavaScript |
| Comunicação | REST API + CORS |

## 📁 Estrutura do Projeto

```
Cash-Flow-node-mobile/

│   ├── style.css
│   └── script.js
├── index.js        # Servidor Express + rotas da API
├── package.json
└── .gitignore
```

## ▶️ Como Rodar

```bash
# Clone o repositório
git clone https://github.com/eder64ghjhj/Cash-Flow-node-mobile.git

# Instale as dependências
npm install

# Configure o banco de dados MySQL
# Crie um banco e ajuste as credenciais em index.js

# Inicie o servidor
node index.js

# Acesse no navegador
http://localhost:3000
```
